AFFICHAGE

Chaque île Reload charge son fond dédié. Si les tuiles locales sont indisponibles, la carte source Fortnite.GG est ouverte dans la vue. Les repères sont propres à chaque île.

Fond de carte introuvable ?

Sur fortnite.gg, ouvre la carte de l’île, F12 → onglet Réseau, filtre « maps/ », fais un clic droit sur une image → Copier l’URL, puis colle-la ici.

Outils d’annotation
DONNÉES DES REPÈRES
Les coffres, boîtes de munitions, distributeurs automatiques, machines à réparer, rampes de lancement, tyroliennes, barils Slurp et camions Slurp disponibles sont lus depuis les données Fortnite.GG de l’île choisie. Si une île Reload n’expose rien : sur fortnite.gg (carte de l’île), ouvre la console (F12), tape copy(JSON.stringify(window.Spawns)), puis clique sur « Coller » ici.

ACTIONS

Clic gauche + glisser : déplacer la carte. Clic bref : placer un point. Cercle ou flèche : deux clics. Sélectionne une annotation pour la modifier ou la supprimer ; molette pour zoomer.

Les spawns Battle Royale viennent des données publiques Fortnite.GG ; les spawns Reload sont consultables sur la carte source dédiée. Les icônes illustrées sont intégrées au fichier. Les annotations personnelles sont enregistrées dans ce navigateur. Les lieux Reload sont recalés par île à partir des coordonnées publiques des POI et du cadrage cartographique propre à chaque fond.
